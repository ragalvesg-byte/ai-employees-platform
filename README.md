# AI Employees Platform

Monorepo for applications, reusable packages, orchestration, knowledge, integrations, and research related to an AI employees platform.

## Structure

```text
apps/
  web/                 Web application
  api/                 API service
  worker/              Background workers
packages/
  agent-core/          Core agent capabilities
  orchestration/       Agent and workflow orchestration
  knowledge/           Knowledge and retrieval
  integrations/        External integrations
  shared/              Shared utilities and types
  ui/                  Reusable user interface
reference-projects/
  coze-studio/
  fastgpt/
  tgo/
docs/
  research/
  architecture/
  licenses/
  decisions/
```
